# TMX Project Manager

TMX Project Manager is a PySide6 desktop application for organising Trackmania
maps into projects. It searches Trackmania Exchange (TMX), stores project data
in Supabase, and exports selected maps as JSON.

> **Project status:** This project is under active development. The current UI
> is designed around a 1920 x 1080 window, and some workflows may still change.

## Features

- Create, edit, archive, and browse map projects.
- Search TMX by map name, author, author ID, map ID, or replay author ID.
- Add and remove maps from a project.
- Record project status, start date, and description.
- Persist projects and maps in Supabase.
- Export project data to JSON.

## Requirements

- Python 3.10 or newer
- A Supabase project with the schema described below
- Internet access for Supabase and TMX API requests

## Installation

Clone the repository and create a virtual environment:

```console
git clone https://github.com/BakedAlaskaTM/ml-projects.git
cd ml-projects
python -m venv .venv
```

Activate the environment:

```console
# Windows PowerShell
.\.venv\Scripts\Activate.ps1

# macOS or Linux
source .venv/bin/activate
```

Install the dependencies:

```console
python -m pip install -r requirements.txt
```

## Configuration

Copy `.env.example` to `.env` and provide your Supabase credentials:

```dotenv
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SECRET_KEY=your-key
```

The application currently uses `SUPABASE_SECRET_KEY`. A service-role key
bypasses Row Level Security and must never be committed, shared, or embedded in
a distributed desktop build. The existing `.gitignore` excludes `.env`.

For public distribution, change the application to use a Supabase publishable
key and configure appropriate Row Level Security policies first. See
[Supabase's API key documentation](https://supabase.com/docs/guides/getting-started/api-keys)
for the distinction between client-safe publishable keys and server-only secret
keys.

## Supabase schema

The application expects these case-sensitive tables and fields:

| Table | Required fields |
| --- | --- |
| `Project` | `slug` (unique), `name`, `is_active`, `status`, `started_at`, `description` |
| `Map` | `uid` (unique), `tmx_id`, `name`, `tmx_author_id`, `author_time` |
| `ProjectMap` | `map_uid`, `project_slug` with a composite unique constraint |

`ProjectMap.map_uid` should reference `Map.uid`, and
`ProjectMap.project_slug` should reference `Project.slug`. Supabase must expose
the `Map` relationship for the application's `Map(*)` query.

Valid project statuses are `ACTIVE`, `PAUSED`, and `ENDED`.

## Running the application

With the virtual environment active and `.env` configured, run:

```console
python main.py
```

The dashboard loads active projects from Supabase. Track searches are sent to
the TMX API when Enter is pressed in the search field.
